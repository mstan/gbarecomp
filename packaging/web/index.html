Browser save

Saves stay in this browser (IndexedDB for this site, on this device) and are never uploaded. Private windows, clearing site data or a different domain lose them: export a copy to keep one. X/Z = A/B, arrows = D-pad, C/V = L/R, Enter = Start, right Shift = Select; Shift+P pauses; Alt+Enter toggles fullscreen. F1–F9 loads; Shift+F1–F9 saves (a Shift key bound to a game button, like Select, never turns a load into a save). Click the game to activate keyboard/gamepad. On touch screens a gamepad is drawn over the game. Sensors, overlay text and the native in-game menu are unavailable.

Query params: ?args=--frames%20600%20--no-window replaces the extra runtime arguments; &env=KEY=VALUE,KEY2=VALUE2 sets environment variables; &rom=file.gba&bios=file.bin picks the served asset names.
