Browser save

Saves stay in this browser (IndexedDB for this site, on this device) and are never uploaded. Private windows, clearing site data or a different domain lose them: export a copy to keep one. X/Z = A/B, arrows = D-pad, C/V = L/R, Enter = Start, right Shift = Select; Shift+P pauses. F1–F9 loads; Shift+F1–F9 saves. Click the game to activate keyboard/gamepad. Sensors and the native overlay are unavailable.

Query params: ?args=--frames%20600%20--no-window replaces the extra runtime arguments; &env=KEY=VALUE,KEY2=VALUE2 sets environment variables; &rom=file.gba&bios=file.bin picks the served asset names.
